# 代码生成：发布菜单 API（与 ZIP 解耦）

> 前端低代码总体规划见兄弟仓库：`geekplus-blog-frontend/docs/lowcode/`

## 原则

- **代码生成**：继续 `GET /generator/downloadByGenTable/{tableIds}` 下载 ZIP，开发者手工合并到前后端工程。
- **发布菜单**：独立接口，只写 `sys_menu` + 可选 `sys_role_menu`，**不读不写**开发者磁盘上的 Vue/Java 文件。
- **幂等**：`sys_menu.component` 全局唯一语义（如 `function/book/index.vue`），已存在则 `alreadyPublished=true`。
- **事务**：主菜单 + 五个按钮在同一 `@Transactional` 内。
- **审计**：`@Log(businessType=PUBLISH)` → `sys_oper_log`；Controller 补充业务日志（operator、module、business、component）。

## 接口

### GET `/generator/table/publishMenuPreview/{tableId}`

返回 `GenPublishMenuPreview`：`component`、`permissionPrefix`、是否已发布等（来自 `gen_table`）。

### POST `/generator/table/publishMenus`

Body `GenPublishMenuRequest`：

| 字段 | 必填 | 说明 |
|------|------|------|
| `tableId` | 是 | gen_table |
| `parentMenuId` | 是 | 父菜单 |
| `menuName` / `path` / `icon` | 否 | 默认 functionName / businessName / table |
| `roleIds` | 否 | 发布后授权角色（已有关联则跳过） |

菜单结构与 `generator/sql/sql.ftl` 一致；`component` 须与合并后的 Vue 路径一致：`{moduleName}/{businessName}/index.vue`。

## 操作流程

1. 代码生成页下载 ZIP → 合并 `views`、`api`、后端 Java。
2. 本地编译/启动验证。
3. 调用 `publishMenus` 或管理端「发布菜单」→ 重新登录或刷新权限。
