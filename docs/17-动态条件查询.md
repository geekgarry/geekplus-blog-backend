# 17 · 动态条件查询（conditionsJson）

与 **GeekPlusAdmin-Security-JWT** 同套 Plus 列表查询方案：前端传 `conditionsJson`，后端白名单解析后由 MyBatis 公共片段拼接。

> 本仓库已完整移植 JWT 侧动态条件相关实现与优化（核心类、公共 XML、BaseEntity、用户列表接入、代码生成模板）。Blog 特有能力（`deptIdList`、`${params.dataScope}`）在接入时保留。

## BaseEntity 字段分工

| 字段 | 是否表列 | 用途 |
|------|----------|------|
| createBy / createTime / updateBy / updateTime / remark / delFlag | 是 | 审计与软删 |
| dataScope | 否 | 行级权限 SQL 占位（`@DataScope` 写入）；与角色配置项不同 |
| beginTime / endTime | 否 | 创建时间区间 → `CreateTimeRange` |
| sortField / sortType | 否 | 排序 → `OrderBy`（白名单） |
| searchValue | 否 | 关键词多列 OR → `KeywordSearch` |
| **conditionsJson** | 否 | 多字段多运算符 → `DynamicWhere`（主路径） |
| params | 否 | 服务端扩展容器（`dq` / `orderByColumn` / `searchColumns`…） |

`searchValue`、时间区间、排序**不能**替代 `conditionsJson`（缺「字段 + 运算符 + 多条件」）。

## 请求约定（相对旧方案的优化）

- **GET** 传 `conditionsJson` **字符串**（JSON 数组），**勿**传嵌套 `dynamicConditions`（Spring GET 嵌套数组绑定不可靠）。
- 示例：`conditionsJson=[{"field":"username","op":"like","value":"admin"},{"field":"status","op":"eq","value":"0"}]`
- 运算符白名单：`eq` `ne` `gt` `ge` `lt` `le` `like` `notLike` `isNull` `isNotNull`
- 可同时附带扁平字段（兼容旧接口）；**有 `params.dq` 时 Mapper 不再应用扁平筛选项**（避免与动态条件重复 AND）。
- 无动态条件时，用户列表字符串筛选项使用 `like concat`（与 JWT 一致，避免只能精确匹配）。

## 接入三步（新业务 / 手工改造）

1. 实体 `implements DynamicQueryColumns`，声明 `field → column` 白名单  
2. Service 列表方法：`DynamicQueryHelper.prepare(entity)`（联表加别名如 `"su"`）；可选 `applyKeywordColumns`  
3. Mapper `<where>` 内 include：`DynamicWhere` + `CreateTimeRange`(或 Aliased) + `KeywordSearch`；`</where>` 后 `OrderBy`；扁平条件包在 `params.dq` 为空时

### 已接入示例：系统用户

- `SysUser` 白名单：username / nickname / phoneNumber / email / status / userType / gender / deptId  
- `SysUserServiceImpl#selectSysUserList` / `selectUnionSysUserList`  
- `SysUserMapper.xml`：保留 Blog 的 `deptIdList` 与 `${params.dataScope}`

## 体积与后期优化方向

- **当前**：后端仅多几个类与一段 XML 片段，对 jar 可忽略；前端为一个小型查询组件 + JSON 字符串参数。  
- **后期可优化**：① 仅在需要的业务页按需引入动态查询组件；② 生成代码默认动态查询可做成开关；③ 未接入的存量 Mapper 不必一口气全改；④ 运算符列表前端可按字段类型裁剪；⑤ 若某环境不用关键词/排序，可不 include 对应 SQL 片段。

## 安全注意

- 列名仅来自白名单 + `isSafeColumn` 正则；运算符枚举限制。  
- 值一律 `#{}` 绑定，禁止把用户输入拼进列名。  
- 勿在文档/日志打印真实 Token。
