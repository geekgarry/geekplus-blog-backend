# 12 · 模块拆分与岗位爬虫 Worker

> 配套：简历 CRUD/AI 与岗位数据服务分域；前端消重见 `resumeAiPayload.js`。

## 包结构（保持单 jar，按域分包）

```
webapp/tool/resume/          # 简历：CRUD + AI 分析
webapp/tool/ppt/             # 独立 PPT：PptController / PptAiService
webapp/tool/job/             # 岗位：搜索 + 深链 + 爬虫
common/util/ai/AiJsonParser
```

**原则：** 暂不拆 Maven 多模块（成本高）；用 package 边界 + `package-info` 保证可读性。远期若 jar 过大，再按 `common / framework / webapp` 切模块。

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| CRUD | `/api/resume` … | 不变 |
| AI | `/api/resume/ai/*` | generate / analyze |
| PPT | `POST /api/ppt/generate` | **独立**；旧 `/api/resume/ai/generate-ppt` 兼容 |
| 搜索 | `POST /api/job/search` | **推荐**；旧 `/api/resume/ai/job-search` 兼容 |
| 爬虫 | `POST /api/job/crawl/run` | 手动触发合规源拉取 |

公开岗位源：`Remotive` · `RemoteOK` · `Arbeitnow`（均无需 Key；国内站走深链）。

## 岗位搜索数据流

```
请求 → JobSearchService
         ├─ JobDeepLinkService     → 平台深链（即时）
         ├─ JobPostingMapper       → 本地库（Worker 写入）
         └─ AiService              → 洞察 / 库不足时补参考岗
```

`dataSource` 字段：`db+deeplink` | `ai+deeplink` | `db+ai+deeplink`。

## 爬虫 Worker

1. 执行 `resources/db/job_posting.sql`
2. 配置：

```yaml
geekplus:
  job:
    crawl:
      enabled: true
      cron: "0 20 */6 * * ?"
      keywords: "frontend,java,product manager"
```

3. 当前样例源：`RemotiveJobSourceClient`（公开 API，可聚合）。  
4. **合规**：国内商业招聘站用深链；新增源实现 `JobSourceClient`，禁止登录态无头爬取。
