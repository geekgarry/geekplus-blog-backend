# 13 · 文件管理大文本读取优化

## 问题

后台「文件管理」查看文本时，用 `el-input` + `v-model` 绑定全文，大文本滚动/框选会触发 Vue 对巨型字符串的响应式更新，页面卡顿。悬停摘要也曾 `read-text` 全量再 `slice(0,120)`。

## 方案

### 后端 `POST /sys/file-manager/read-text`

| 参数 | 说明 |
|------|------|
| `path` | 相对路径 |
| `maxChars`（可选） | &gt;0 时只流式读取前 N 个字符（悬停摘要） |

- 全文读取：单文件 **&gt;5MB** 直接拒绝，提示下载本地打开  
- 使用 `BufferedReader` 流式拼接，避免 `Files.lines().collect` 全量行缓冲  
- `save-text` 使用 try-with-resources 写盘  

### 前端

- 文本预览改为**原生 `textarea`**，正文写入 DOM，**不进 Vue data**  
- 保存时从 `ref.value` 取值提交  
- 悬停：`maxChars=200`；&gt;2MB 文件不请求正文  
- &gt;5MB：弹窗内引导下载，不打开编辑区  

## 代码

- `FileService#readTextFile(path, maxChars)`  
- `FileManagerController#readTextFile`  
- 前端：`views/admin/system/file/index.vue`、`api/system/file-manager.js`
